This page is a plain web form — it has nothing to do with the AI chat. It demonstrates that the keyboard is a reusable component: any app can drop in amharic-keyboard.js + amharic-keyboard.css, give it an input element and a dictionary, and get Gboard-style typing with spelling-invariant word search + Bible-trained next-word hints.
